АЛИСА ДЛЯ ZELLO — стартовый Android-проект

Это интерфейсный прототип, а не готовый голосовой бот.
Сейчас доступны экран управления, локальный переключатель и редактирование списка каналов.
Не реализованы: вход в Zello, подключение к каналам, передача голоса, распознавание речи, ответы ИИ, фоновая работа и музыка.

Сборка APK выполняется через GitHub Actions. После успешной сборки APK будет доступен как artifact.
Не помещайте пароли, токены или приватные ключи в исходный код.
